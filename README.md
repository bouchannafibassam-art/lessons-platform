# منصة الدروس - جميع المستويات

هذه النسخة تحتوي على 12 مستوى دراسي من الأولى ابتدائي حتى الثانية باكالوريا، و7 مواد لكل مستوى، و12 درساً لكل مادة (1008 درساً) مع رابط فيديو YouTube محفوظ لكل درس.

ملاحظة: روابط الفيديو المدمجة هي روابط بحث YouTube حسب عنوان الدرس، وليست ملفات فيديو محلية ولا ادعاء بأنها فيديوهات رسمية للمنهاج. يمكن تغيير الرابط من لوحة Admin إلى فيديو محدد.

## التشغيل على Windows
1. فك الضغط بالكامل.
2. شغّل `START.bat`.
3. افتح http://127.0.0.1:5000

Admin: `/admin` — كلمة السر الافتراضية `admin123`.
